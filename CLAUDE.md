# Working preferences

- "Copy-paste code" means a self-contained shell heredoc that runs Python
  directly in the terminal, in this form:

  ```bash
  python3 - <<'EOF'
  ...python code...
  EOF
  ```

  Use full cluster paths (e.g. /home/ZhangJianfeng_04/emo_study/...), no
  placeholders, and nothing that has to be edited before running.
